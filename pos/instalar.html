Facturación electrónica AFIP Opcional
Necesario para emitir Facturas A y B electrónicas con CAE. Si todavía no hiciste los trámites en AFIP, omitilo y configuralo después.
Antes de subir el certificado necesitás hacer 4 pasos en el portal de AFIP (afip.gob.ar). Si ya los hiciste, subí el archivo abajo.
1
Tener clave fiscal nivel 3 Necesitás clave fiscal con nivel de seguridad 3 o superior. Si solo tenés nivel 2, solicitá la suba de nivel en cualquier agencia de AFIP o por TAD.
2
Adherir el servicio de Factura Electrónica Ingresá con tu CUIT y clave fiscal → Administrador de Relaciones → Adherir Servicio → buscá wsfe (Facturación Electrónica versión 1) → seleccioná tu CUIT como representado y confirmá.
3
Crear y descargar el certificado digital (.p12) Desde el menú principal → Administración de Certificados Digitales → Nueva solicitud de certificado → completá los datos → descargá el archivo .p12 y guardá bien la contraseña. El certificado tiene vigencia de 2 años.
4
Habilitar un punto de venta para Web Services Desde el menú principal → Comprobantes en línea → Datos adicionales del comprobante → ABM Puntos de Venta → creá un nuevo PV de tipo BFEWS — Web Services. El número que le asignes es el que tenés que usar en el campo "Punto de venta AFIP" del sistema.
Usá Homologación para probar que todo funciona antes de pasar a Producción.
